# Devices v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One floor on this laptop starts and controls Claude Code agents that run on other Linux machines over Tailscale SSH, so their worktrees, type-checks, suites and dev servers use those machines' CPU and RAM, and the agents keep working when a link drops.

**Architecture:** One `DeviceLink` per configured device owns an SSH ControlMaster that carries three reverse forwards (hive SFTP, hooks, OTLP). The link mounts this laptop's hive on the device with `sshfs -o directport`, and runs one-shot commands over the master (`exec`). A remote agent's terminal is still a node-pty process, now `ssh -tt … tmux -L md new-session -A …`, which runs a `launch.sh` the app writes into the hive. Above the pty nothing changes. Hooks reach the floor over a forwarded TCP port, and after N minutes cut off they stop the agent's turn ("pause"). The link nudges the agent when it comes back.

**Tech Stack:** Electron main process (TypeScript), node-pty, the OpenSSH client and this laptop's `sftp-server`, tmux and sshfs on the device, React + zustand + react-i18next in the renderer, `node:test` for tests.

**Spec:** `docs/superpowers/specs/2026-10-29-devices-design.md` (read it before starting any task; this plan argues from it).

- `config.json`: `devices?: DeviceConfig[]` with `DeviceConfig = { id: string; host: string; user?: string; portBase?: number }`, and `deviceOfflinePauseMin?: number` (default 10, 0 = never pause). This laptop is the implicit device `local` and is never stored.

## Review Focus

The five failure modes most likely to bite a person using this, each pinned by a test in the task that owns the code:

1. **A prompt or env value with newlines, quotes, `$`, backticks or unicode** has to cross ssh, then the login shell, then tmux, then `launch.sh`. It must reach `claude` byte for byte. Pinned: Task 2, test "a multi-line prompt and its env reach claude unchanged…".
2. **A stale ControlPath left by a crashed app.** Real `ssh -M` then quietly runs as a plain client and never answers `-O check`, so the device would sit in "connecting" forever. The link must clear it and connect. Pinned: Task 4, test "a stale ControlPath from a crash is cleared…".
3. **Login-shell rc noise** (motd, nvm banners, `.bash_logout`) in `exec` output. git, `tmux ls` and the paused-file check must see only the command's own output and exit code. Pinned: Task 2 fence test and Task 4, test "exec returns only the command's output…".
4. **A device-side port already in use.** `ExitOnForwardFailure` makes the master exit at once. The user must see which port and what to change, not a silent reconnect loop. Pinned: Task 4, test "a device-side port in use…".
5. **A device offline at quit, or an app crash.** `md-*` sessions are left on the device. The next connect must keep the sessions the restore flow brings back and kill the rest. A terminal that dies because the link died must never archive a live agent. Pinned: Task 8 tests.

```ts
/**
 * Devices: other Linux machines that run agents for this floor
 * (docs/superpowers/specs/2026-10-29-devices-design.md). Shared by main,
 * preload and renderer, so the config shape and its validation live once.
 *
 * This laptop is the implicit device `local` and is never stored.
 */

export interface DeviceConfig {
  /** 'my-lap'; also the label on agent cards and part of the ControlPath. */
  id: string;
  /** Tailscale IP or name ('100.65.189.1'). */
  host: string;
  /** Login name on the device. Default: this laptop's username. */
  user?: string;
  /** Device loopback ports: base = SFTP, +1 = hooks, +2 = telemetry. Each
   *  device has its own loopback, so every device can use the same base. */
  portBase?: number;
}

export type DeviceState = 'offline' | 'connecting' | 'online';

export interface DeviceStatus {
  id: string;
  state: DeviceState;
  /** Why the last attempt failed, in words a person can act on. */
  error?: string;
}

/** One line of Settings → Devices → Check. `fix` is a command, shown on failure. */
export interface DeviceCheckItem {
  id: 'login' | 'claude' | 'node' | 'tmux' | 'sshfs' | 'mount' | 'folder';
  /** The agent folder, for `folder` items. */
  path?: string;
  ok: boolean;
  fix?: string;
}

export const LOCAL_DEVICE = 'local';
export const DEFAULT_PORT_BASE = 47990;
export const DEFAULT_OFFLINE_PAUSE_MIN = 10;

// An id ends up in a socket path (/run/user/<uid>/md-<id>.ctl must stay under
// 108 bytes) and on agent cards. A host and a user end up in ssh's argv,
// where a leading '-' would be read as an option (`-oProxyCommand=…`), so
// both are held to plain name characters.
const ID_RE = /^[A-Za-z0-9_-]{1,32}$/;
const HOST_RE = /^[A-Za-z0-9][A-Za-z0-9.:-]{0,252}$/;
const USER_RE = /^[A-Za-z_][A-Za-z0-9_.-]{0,31}$/;

/** '' and 'local' both mean this laptop; anything else is a device id. */
export function normalizeDeviceId(device: unknown): string | undefined {
  if (typeof device !== 'string') return undefined;
  const d = device.trim();
  return d && d !== LOCAL_DEVICE ? d : undefined;
}

/** Can `id` name a new device, given the ids already taken? */
export function isValidDeviceId(id: string, taken: string[] = []): boolean {
  return ID_RE.test(id) && id !== LOCAL_DEVICE && !taken.includes(id);
}

export function isValidDeviceHost(host: string): boolean {
  return HOST_RE.test(host);
}

/** Keep the well-formed entries of a device list, drop the rest. A bad
 *  optional field is dropped on its own; the device stays. */
export function normalizeDevices(raw: unknown): DeviceConfig[] {
  if (!Array.isArray(raw)) return [];
  const out: DeviceConfig[] = [];
  for (const r of raw) {
    if (!r || typeof r !== 'object') continue;
    const { id, host, user, portBase } = r as Record<string, unknown>;
    if (typeof id !== 'string' || !isValidDeviceId(id, out.map((d) => d.id))) continue;
    if (typeof host !== 'string' || !isValidDeviceHost(host)) continue;
    const d: DeviceConfig = { id, host };
    if (typeof user === 'string' && USER_RE.test(user)) d.user = user;
    if (typeof portBase === 'number' && Number.isInteger(portBase) && portBase >= 1024 && portBase <= 65533) d.portBase = portBase;
    out.push(d);
  }
  return out;
}
```

```ts
/**
 * Devices: every command and argv the device link sends, and the parsers for
 * what comes back (spec: docs/superpowers/specs/2026-10-29-devices-design.md).
 *
 * Pure: no I/O, no Electron. test/device-commands.test.cjs runs each string
 * through a real shell with fake binaries, because a quoting bug only shows
 * when a shell parses the result.
 *
 * The quoting rule: every value is POSIX-single-quoted once, at the layer that
 * parses it. A command that crosses ssh travels as ONE string (sshd joins its
 * argv with spaces and hands the result to the user's login shell), so it is
 * always `bash -lc '<cmd>'`: a known shell, with the device's login PATH,
 * where `~/.local/bin/claude` lives.
 */
import { DEFAULT_PORT_BASE, type DeviceCheckItem, type DeviceConfig } from '../shared/devices';
import { projectKey } from './transcript';

/** POSIX single quotes: safe for any string, newlines and unicode included. */
export function shq(s: string): string {
  return `'${s.replace(/'/g, `'\\''`)}'`;
}

// ─── ssh ─────────────────────────────────────────────────────────────────────

export function portBase(d: DeviceConfig): number {
  return d.portBase ?? DEFAULT_PORT_BASE;
}

export function sshTarget(d: DeviceConfig, localUser: string): string {
  return `${d.user ?? localUser}@${d.host}`;
}

/** A Unix socket path must stay under 108 bytes, hence /run/user/<uid>. */
export function controlPath(deviceId: string, runDir: string): string {
  return `${runDir}/md-${deviceId}.ctl`;
}

/** The ControlMaster. No command (-N), never prompts (BatchMode), and exits
 *  rather than run without a forward (ExitOnForwardFailure). A dead link is
 *  noticed in about 45 s (ServerAlive 15 × 3). Remote Unix-socket forwards
 *  are broken under Tailscale SSH, so every forward listens on a device-side
 *  loopback TCP port; the hook one lands on hooks.sock here. */
export function masterArgs(
  d: DeviceConfig,
  ctl: string,
  localUser: string,
  ports: { sftp: number; hookSock: string; telemetry: number | null }
): string[] {
  const base = portBase(d);
  return [
    '-M', '-S', ctl, '-N',
    '-o', 'BatchMode=yes', '-o', 'ExitOnForwardFailure=yes',
    '-o', 'ServerAliveInterval=15', '-o', 'ServerAliveCountMax=3',
    '-R', `127.0.0.1:${base}:127.0.0.1:${ports.sftp}`,
    '-R', `127.0.0.1:${base + 1}:${ports.hookSock}`,
    ...(ports.telemetry ? ['-R', `127.0.0.1:${base + 2}:127.0.0.1:${ports.telemetry}`] : []),
    sshTarget(d, localUser)
  ];
}

export function controlArgs(ctl: string, target: string, op: 'check' | 'exit'): string[] {
  return ['-S', ctl, '-O', op, target];
}

/** Why the master exited, in words a person can act on. `fallback` is the
 *  link's own reason when it ended the master itself. A busy port still wins,
 *  because that is the thing that needs fixing. */
export function masterExitReason(stderr: string, deviceId: string, fallback?: string): string {
  const port = /remote port forwarding failed for listen port (\d+)/.exec(stderr);
  if (port) {
    return `Port ${port[1]} is already in use on ${deviceId}. Free it there, or give ${deviceId} another portBase in config.json.`;
  }
  if (fallback) return fallback;
  const last = stderr.split('\n').map((l) => l.trim()).filter(Boolean).pop();
  return last ? `${deviceId}: ${last}` : `Lost the connection to ${deviceId}.`;
}

const BACKOFF_MS = [2_000, 5_000, 15_000, 30_000, 60_000];

/** Reconnect delay after the `attempt`-th failure in a row (0-based). */
export function backoffDelay(attempt: number): number {
  return BACKOFF_MS[Math.min(attempt, BACKOFF_MS.length - 1)];
}

// ─── One-shot commands (`exec`) ──────────────────────────────────────────────

const BEGIN = '__MD_BEGIN__';
const END = '__MD_END__';

/** Fence a command's output so whatever the login shell's rc files print
 *  around it (motd, nvm banners, an `echo` in .bashrc, .bash_logout) is cut
 *  away. The subshell keeps an `exit` in `cmd` from skipping the end mark. */
export function fence(cmd: string): string {
  return `printf '%s\\n' ${BEGIN}; (\n${cmd}\n); printf '\\n%s %d\\n' ${END} $?`;
}

/** The fenced output and exit code, or null when the fence never printed
 *  (ssh failed before the command ran). */
export function parseFenced(stdout: string): { out: string; code: number } | null {
  const b = stdout.indexOf(`${BEGIN}\n`);
  if (b < 0) return null;
  const from = b + BEGIN.length + 1;
  const e = stdout.lastIndexOf(`\n${END} `);
  if (e < from) return null;
  const code = parseInt(stdout.slice(e + END.length + 2), 10);
  return Number.isFinite(code) ? { out: stdout.slice(from, e), code } : null;
}

export function execArgs(ctl: string, target: string, cmd: string): string[] {
  return ['-S', ctl, '-o', 'BatchMode=yes', target, '--', `bash -lc ${shq(fence(cmd))}`];
}

/** Mount this laptop's hive at the same path on the device, through the

}
```

```ts
/**
 * The hive's SFTP server, for devices (spec: "Device link", item 2).
 *
 * A device mounts this laptop's hive with `sshfs -o directport=<base>`, which
 * speaks raw SFTP to a TCP port; the link's `-R <base>:127.0.0.1:<port>`
 * forward carries that port here. Measured on the real machines: through such
 * a forward the mount survives a link cut (reads and writes fail at once with
 * EIO, nothing is written locally) and works again by itself when the link is
 * back.
 *
 * One loopback listener serves every device. Each connection gets its own
 * `sftp-server` child (this laptop's OpenSSH binary, run as this user) with
 * the socket piped through it, so there is no socat dependency.
 */
import { spawn } from 'node:child_process';
import { existsSync } from 'node:fs';
import { createServer } from 'node:net';

export const SFTP_SERVER_PATHS = [
  '/usr/lib/ssh/sftp-server',
  '/usr/lib/openssh/sftp-server',
  '/usr/libexec/openssh/sftp-server',
  '/usr/libexec/sftp-server'
];

export function findSftpServer(candidates: string[] = SFTP_SERVER_PATHS): string | null {
  return candidates.find((p) => existsSync(p)) ?? null;
}

export interface SftpServer {
  port: number;
  close(): void;
}

export function startSftpServer(candidates: string[] = SFTP_SERVER_PATHS): Promise<SftpServer> {
  const bin = findSftpServer(candidates);
  if (!bin) {
    return Promise.reject(new Error(
      `No sftp-server on this laptop (looked in ${candidates.join(', ')}). Install OpenSSH to run agents on devices.`
    ));
  }
  const server = createServer((sock) => {
    const child = spawn(bin, [], { stdio: ['pipe', 'pipe', 'ignore'] });
    sock.pipe(child.stdin);
    child.stdout.pipe(sock);
    const end = (): void => {
      try { child.kill(); } catch { /* already gone */ }
      sock.destroy();
    };
    sock.on('error', end);
    sock.on('close', end);
    child.on('error', end);
    child.on('exit', () => sock.end());
    // A socket that closes mid-write must not crash the main process.
    child.stdin.on('error', () => {});
  });
  return new Promise((resolve, reject) => {
    server.once('error', reject);
    // Loopback only: the device reaches it through the ssh forward, nothing else can.
    server.listen(0, '127.0.0.1', () => {
      const addr = server.address();
      const port = typeof addr === 'object' && addr ? addr.port : 0;
      resolve({ port, close: () => server.close() });
    });
  });
}
```

```js
function waitForState(link, state, ms = 10_000) {
  if (link.state === state) return Promise.resolve(link.status());
  return new Promise((resolve, reject) => {
    const timer = setTimeout(() => {
      link.off('state', on);
      reject(new Error(`timed out waiting for ${state}; last: ${JSON.stringify(link.status())}`));
    }, ms);
    function on(s) {
      if (s.state !== state) return;
      clearTimeout(timer);
      link.off('state', on);
      resolve(s);
    }
    link.on('state', on);
  });
}
```

```ts
/**
 * Devices: one SSH link per configured device (spec: "Device link").
 *
 * A link owns one ControlMaster `ssh` that carries three reverse forwards
 * (hive SFTP, hooks, telemetry). It mounts this laptop's hive on the device
 * through the first, and runs every other remote command as a short-lived
 * client of that master (`exec`). When the master exits, the device goes
 * offline and the link reconnects on a backoff of 2 s, 5 s, 15 s, 30 s, then
 * every 60 s. Agents' terminals are `ssh -tt` clients of the same master
 * (remoteTerminal below), so a dead link ends them too; index.ts reattaches
 * them when the link emits `online` again.
 *
 * Events: 'state' (DeviceStatus) on every change; 'online' once the hive is
 * mounted, which is the moment a device can take agents.
 */
import { spawn, type ChildProcess } from 'node:child_process';
import { EventEmitter } from 'node:events';
import { existsSync, mkdirSync, rmSync } from 'node:fs';
import { tmpdir, userInfo } from 'node:os';
import { dirname } from 'node:path';
import type { DeviceConfig, DeviceState, DeviceStatus } from '../shared/devices';
import {
  backoffDelay, controlArgs, controlPath, execArgs, installShimCommand, masterArgs,
  masterExitReason, mountCommand, NOT_EMPTY, parseFenced, portBase, sshTarget
} from './deviceCommands';

export interface ExecResult {
  /** The command ran on the device and exited 0. */
  ok: boolean;
  /** Its exit code, or -1 when it never ran (offline, timeout, ssh failed). */
  code: number;
  stdout: string;
  stderr: string;
  error?: string;
}

/** What a link needs from the app around it. The last four are test seams. */
export interface LinkEnv {
  hiveRoot: string;
  hookSock: string;
  /** The shared SFTP server's port, or null when it could not start. */
  sftpPort: number | null;
  sftpError?: string;
  /** The OTLP collector's port, or null when telemetry is off. */
  telemetryPort: number | null;
  sshBin?: string;
  sshEnv?: NodeJS.ProcessEnv;
  runDir?: string;
  backoff?: (attempt: number) => number;
}

/** /run/user/<uid> keeps the ControlPath short; a Unix socket path must be under 108 bytes. */
function defaultRunDir(): string {
  const d = `/run/user/${userInfo().uid}`;
  return existsSync(d) ? d : tmpdir();
}

export class DeviceLink extends EventEmitter {
  state: DeviceState = 'offline';
  error: string | undefined;
  private master: ChildProcess | null = null;
  private running = false;
  private attempt = 0;
  private retry: NodeJS.Timeout | null = null;
  /** Set when the link ends the master itself, so the exit says why. */
  private killReason: string | undefined;

  constructor(readonly device: DeviceConfig, private readonly env: LinkEnv) {
    super();
  }

  get id(): string { return this.device.id; }
  get portBase(): number { return portBase(this.device); }
  get sshBin(): string { return this.env.sshBin ?? 'ssh'; }
  ctl(): string { return controlPath(this.id, this.env.runDir ?? defaultRunDir()); }
  target(): string { return sshTarget(this.device, userInfo().username); }
  status(): DeviceStatus {
    return this.error ? { id: this.id, state: this.state, error: this.error } : { id: this.id, state: this.state };
  }

  /** Idempotent: a link never runs two masters. */
  start(): void {
    if (this.running) return;
    this.running = true;
    void this.connect();
  }

  stop(): void {
    this.running = false;
    if (this.retry) clearTimeout(this.retry);
    this.retry = null;
    const m = this.master;
    this.master = null;
    if (m) { try { m.kill(); } catch { /* already gone */ } }
    rmSync(this.ctl(), { force: true });
    this.setState('offline', undefined);
  }

  /** Run one command on the device over the master, under `bash -lc` so it
   *  sees the login PATH. Fails at once while the device is not online. */
  exec(cmd: string, timeoutMs = 15_000): Promise<ExecResult> {
    if (this.state !== 'online') {
      return Promise.resolve({ ok: false, code: -1, stdout: '', stderr: '', error: `${this.id} is offline` });
    }
    return this.run(cmd, timeoutMs);
  }

  private setState(state: DeviceState, error: string | undefined): void {
    this.state = state;
    this.error = error;
    this.emit('state', this.status());
  }

  private async connect(): Promise<void> {
    if (!this.running || this.master) return;
    if (this.env.sftpPort === null) {
      // Nothing to retry: the SFTP server is this laptop's, and it did not start.
      this.setState('offline', this.env.sftpError ?? 'No SFTP server on this laptop.');
      return;
    }
    // Keep the last error showing while we try again.
    this.setState('connecting', this.error);
    await this.clearStaleControlPath();
    if (!this.running) return;
    mkdirSync(dirname(this.ctl()), { recursive: true });
    let stderr = '';
    const m = spawn(this.sshBin, masterArgs(this.device, this.ctl(), userInfo().username, {
      sftp: this.env.sftpPort,
      hookSock: this.env.hookSock,
      telemetry: this.env.telemetryPort
    }), { stdio: ['ignore', 'ignore', 'pipe'], env: this.env.sshEnv });
    this.master = m;
    const gone = (): void => {
      if (this.master !== m) return; // stop(), or already handled
      this.master = null;
      const why = masterExitReason(stderr, this.id, this.killReason);
      this.killReason = undefined;
      this.setState('offline', why);
      this.scheduleReconnect();
    };
    m.stderr?.on('data', (d) => { stderr = (stderr + d.toString()).slice(-4000); });
    m.on('error', (e) => { stderr += `\n${e.message}`; gone(); });
    m.on('close', gone);

    if (!(await this.waitForMaster(m))) return;
    const mount = await this.run(`${mountCommand(this.env.hiveRoot, this.portBase)} && ${installShimCommand(this.env.hiveRoot)}`, 30_000);
    if (this.master !== m) return;
    if (!mount.ok) {
      this.killReason = mount.stdout.includes(NOT_EMPTY)
        ? `The hive folder on ${this.id} is not empty, so it was not mounted. Move it aside on ${this.id}: mv ${this.env.hiveRoot} ${this.env.hiveRoot}.local`
        : `Could not mount the hive on ${this.id}: ${mount.error ?? (mount.stderr.trim() || `exit ${mount.code}`)}`;
      m.kill();
      return;
    }
    this.attempt = 0;
    this.setState('online', undefined);
    this.emit('online');
  }

  /** The master gives no "ready" signal, so ask it (`-O check`) until it answers. */
  private async waitForMaster(m: ChildProcess, timeoutMs = 20_000): Promise<boolean> {
    const until = Date.now() + timeoutMs;
    while (this.master === m && Date.now() < until) {
      const r = await this.spawnSsh(controlArgs(this.ctl(), this.target(), 'check'), 5_000);
      if (r.code === 0) return this.master === m;
      await new Promise((res) => setTimeout(res, 300));
    }
    if (this.master === m) {
      this.killReason = `${this.id} did not answer within ${timeoutMs / 1000} s.`;
      m.kill();
    }
    return false;
  }

  /** A ControlPath left by a crashed app makes a new `ssh -M` quietly run as
   *  a plain client ("ControlSocket … already exists, disabling
   *  multiplexing") that never answers `-O check`. Ask any old master to exit
   *  (its forwards point at ports of an app that is gone), then remove it. */
  private async clearStaleControlPath(): Promise<void> {
    if (!existsSync(this.ctl())) return;
    await this.spawnSsh(controlArgs(this.ctl(), this.target(), 'exit'), 3_000);
    rmSync(this.ctl(), { force: true });
  }

  private scheduleReconnect(): void {
    if (!this.running) return;
    const delay = (this.env.backoff ?? backoffDelay)(this.attempt++);
    this.retry = setTimeout(() => { this.retry = null; void this.connect(); }, delay);
  }

  private async run(cmd: string, timeoutMs: number): Promise<ExecResult> {
    const r = await this.spawnSsh(execArgs(this.ctl(), this.target(), cmd), timeoutMs);
    const fenced = parseFenced(r.stdout);
    if (!fenced) {
      return { ok: false, code: -1, stdout: '', stderr: r.stderr, error: r.stderr.trim().split('\n').pop() || `No answer from ${this.id}.` };
    }
    return { ok: fenced.code === 0, code: fenced.code, stdout: fenced.out, stderr: r.stderr };
  }

  private spawnSsh(args: string[], timeoutMs: number): Promise<{ code: number; stdout: string; stderr: string }> {
    return new Promise((resolve) => {
      const p = spawn(this.sshBin, args, { stdio: ['ignore', 'pipe', 'pipe'], env: this.env.sshEnv });
      let stdout = '';
      let stderr = '';
      const timer = setTimeout(() => { try { p.kill('SIGKILL'); } catch { /* gone */ } }, timeoutMs);
      p.stdout?.on('data', (d) => { stdout += d.toString(); });
      p.stderr?.on('data', (d) => { stderr += d.toString(); });
      p.on('error', (e) => { clearTimeout(timer); resolve({ code: -1, stdout, stderr: `${stderr}${e.message}` }); });
      p.on('close', (code) => { clearTimeout(timer); resolve({ code: code ?? -1, stdout, stderr }); });
    });
  }
}

/** The running links, one per configured device. */
export class DeviceRegistry extends EventEmitter {
  private links = new Map<string, DeviceLink>();

  constructor(private readonly env: () => LinkEnv) {
    super();
  }

  /** Match the running links to the configured devices: start new ones, stop
   *  removed ones, and restart one whose host, user or ports changed. */
  sync(devices: DeviceConfig[]): void {
    const want = new Map(devices.map((d) => [d.id, d]));
    for (const [id, link] of this.links) {
      const d = want.get(id);
      if (d && JSON.stringify(d) === JSON.stringify(link.device)) continue;
      link.stop();
      link.removeAllListeners();
      this.links.delete(id);
    }
    for (const d of devices) {
      if (this.links.has(d.id)) continue;
      const link = new DeviceLink(d, this.env());
      link.on('state', (s: DeviceStatus) => this.emit('state', s));
      link.on('online', () => this.emit('online', link));
      this.links.set(d.id, link);
      link.start();
    }
  }

  get(id: string): DeviceLink | undefined { return this.links.get(id); }
  all(): DeviceLink[] { return [...this.links.values()]; }
  statuses(): DeviceStatus[] { return this.all().map((l) => l.status()); }
  stopAll(): void { for (const l of this.links.values()) l.stop(); }
}
```

```ts
 *  return the pty spawn: `ssh -tt … tmux new-session -A …`. pty.ts stays the

export function remoteTerminal(
  link: DeviceLink,
  hiveRoot: string,
  o: { ptyId: string; agentId: string; cwd: string; env: Record<string, string>; args: string[]; cols?: number; rows?: number }
): SpawnOptions {
  const launch = launchPath(hiveRoot, o.agentId);
  mkdirSync(dirname(launch), { recursive: true });
```

```bash
#!/usr/bin/env bash
# Devices: before/after load numbers (docs/perf/devices-load.md).
#
# Samples this laptop's 1-minute load average and MemAvailable, then prints
# p50 and p95 of load1 and the minimum MemAvailable.
#
#   scripts/devices-load.sh <label> [samples=60] [interval-seconds=30]
#
# The default is 60 samples 30 s apart: 30 minutes. Writes
# ${DEVICES_LOAD_DIR:-docs/perf}/devices-load-<label>.csv.
set -euo pipefail

LABEL=${1:?usage: scripts/devices-load.sh <label> [samples] [interval-seconds]}
N=${2:-60}
IV=${3:-30}
DIR=${DEVICES_LOAD_DIR:-$(cd "$(dirname "$0")/.." && pwd)/docs/perf}
OUT="$DIR/devices-load-$LABEL.csv"
mkdir -p "$DIR"

echo 'epoch,load1,mem_available_mb' > "$OUT"
for i in $(seq "$N"); do
  read -r L1 _ < /proc/loadavg
  MA=$(awk '/^MemAvailable:/ { printf "%d", $2 / 1024 }' /proc/meminfo)
  echo "$(date +%s),$L1,$MA" >> "$OUT"
  if [ "$i" -lt "$N" ]; then sleep "$IV"; fi
done

# Nearest-rank percentiles: the value at rank ceil(p/100 * n) of the sorted samples.
tail -n +2 "$OUT" | cut -d, -f2 | sort -n | awk '
  { v[NR] = $1 }
  END {
    r50 = int((NR * 50 + 99) / 100); r95 = int((NR * 95 + 99) / 100)
    printf "samples=%d load1_p50=%s load1_p95=%s\n", NR, v[r50], v[r95]
  }'
tail -n +2 "$OUT" | cut -d, -f3 | sort -n | head -1 | awk '{ printf "mem_available_min_mb=%s\n", $1 }'
echo "csv=$OUT"
```
